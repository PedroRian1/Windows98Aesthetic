# 💻 Windows 98 - Site de Curiosidades

Este é um site interativo que usa o visual clássico do sistema operacional Windows 98. Ele funciona como um painel onde o usuário pode clicar em botões para ler fatos curiosos sobre a história do sistema.

## 🚀 O que o site faz

*   **Visual Retrô:** Tem as cores originais (fundo verde e janelas cinzas), botões que afundam ao clicar e letras da época.
*   **10 Curiosidades:** O usuário clica em um dos 10 botões e uma janela se abre no meio da tela mostrando uma história sobre o Windows 98.
*   **Relógio Real:** Na barra inferior (Barra de Tarefas), há um relógio que puxa a hora certa do computador e atualiza sozinho.
*   **Funciona no Celular:** O topo e os menus diminuem de tamanho automaticamente para caber em telas menores.

## 🛠️ Tecnologias usadas

O site foi feito do zero, sem usar nenhuma biblioteca externa de terceiros:
*   **HTML:** Para criar a estrutura das janelas, botões e textos.
*   **CSS:** Para fazer o visual tridimensional (3D) e as cores dos anos 90.
*   **JavaScript:** Para fazer as mensagens aparecerem na tela e fazer o relógio funcionar.
